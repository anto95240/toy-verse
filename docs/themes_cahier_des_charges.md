## 3. Architecture retenue — Hybride

### Spécificité Toy-Verse : Catégories & Sous-Catégories
Contrairement à GameCollector (qui utilise un système de tags ou de genres de jeux), le système de déblocage de Toy-Verse s'appuie sur l'arborescence **Catégorie** et **Sous-Catégorie** des jouets (ex: Catégorie = `Véhicules`, Sous-catégorie = `Radiocommandé` ou `Hot Wheels`).

```sql
CREATE TABLE themes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  id_name VARCHAR NOT NULL UNIQUE,
  display_name VARCHAR NOT NULL,
  type VARCHAR NOT NULL,
  is_dark BOOLEAN DEFAULT true,
  default_color VARCHAR,
  unlock_type VARCHAR DEFAULT 'trophy', -- 'default'|'trophy'|'collection'|'date'
  required_achievement_id UUID REFERENCES achievements(id),
  required_item_count INTEGER,
  required_category VARCHAR,    -- ex: 'Véhicules', 'Construction', 'Figurines'
  required_subcategory VARCHAR, -- ex: 'Hot Wheels', 'Lego', 'Marvel'
  date_start VARCHAR, date_end VARCHAR,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE user_themes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  theme_id UUID NOT NULL REFERENCES themes(id),
  is_equipped BOOLEAN DEFAULT false,
  unlocked_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(user_id, theme_id)
);
```

**Anti-FOUC Next.js (script inline `<head>`) :**
```tsx
<script dangerouslySetInnerHTML={{ __html: `
  try {
    const p = localStorage.getItem('theme-preset') || 'neon-night';
    document.documentElement.setAttribute('data-preset', p);
  } catch(e) {}
`}} />
```

## 4. 🎬 Guide des animations immersives

Chaque thème dispose de **3 couches d'animation ultra-détaillées** pour garantir une immersion totale :

| Couche | Rôle | Technique CSS |
|---|---|---|
| **Fond ambiant** | Atmosphère générale, toujours visible | `@keyframes` sur `background-position` / `filter: hue-rotate` |
| **Particules** | Éléments visuels flottants (bulles, flocons, étincelles) | `::before` / `::after` + `box-shadow` multi-valeurs |
| **Micro-interactions** | Réactivité hover, pulse, respiration | `transition` + `animation-play-state` sur hover |

### 🏷️ Tags techniques

- `[GRADIENT-ANIM]` — Background animé
- `[PARTICLES]` — Particules CSS pures
- `[FILTER]` — Filtres CSS (blur, hue-rotate, brightness)
- `[PSEUDO-ELEM]` — Overlay `::before`/`::after`
- `[JS-LIGHT]` — Script léger (~20 lignes) pour effets impossibles CSS pur
- `[KEYFRAME-3D]` — Transformations CSS 3D
